working 
Automated video surveillance systems makes the computer vision to perform object identification, tracking, and classification. In public safety contexts, verifying mask compliance requires real-time processing with low latency. Standard object detection algorithms often face trade-offs between processing speed and accuracy.

This implementation addresses these constraints by decoupling the pipeline into two discrete phases:

Face Detection: Rapid spatial localization of facial regions within video frames using Haar Feature-based Cascade Classifiers.

Mask Classification: Binary classification of localized face regions using a transfer learning model derived from MobileNetV2.

By constraining the deep learning inference step strictly to cropped facial regions rather than full high-resolution frames, the system maintains efficient CPU utilization while preserving high classification accuracy.
